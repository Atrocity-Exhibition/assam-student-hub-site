# AssamStudentHub

AssamStudentHub is a modern platform for discovering:

- Assam government jobs
- Scholarships
- University notices
- Exam updates
- Admissions
- Student opportunities

Built using:

- Next.js
- TypeScript
- TailwindCSS
- Supabase (planned)

## Features

- Modern responsive UI
- Search-first homepage
- Job aggregation
- University discovery
- Mobile-friendly design
- SEO-focused architecture

## Tech Stack

- Next.js App Router
- TypeScript
- TailwindCSS
- Framer Motion (planned)
- Supabase (planned)

## Development

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Open:

[http://localhost:3000](http://localhost:3000)
